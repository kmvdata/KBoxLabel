# KBoxLabel

KBoxLabel 是一个基于 PyQt5 开发的专业图像标注工具，专为计算机视觉中的目标检测任务设计。它提供了直观的图形界面和多种标注格式支持，帮助用户高效完成图像标注工作。KBoxLabel 特别适合机器学习工程师、研究人员和数据科学家准备训练数据集。

## 核心功能

### 图形界面与操作
- 基于 PyQt5 构建的直观易用操作界面
- 支持跨平台运行（Windows、macOS 和 Linux）
- 提供丰富的键盘快捷键提升标注效率
- 支持多项目窗口同时管理
- 实时保存标注数据到SQLite数据库

### 标注支持
- 支持矩形框标注，适用于目标检测任务
- 集成 YOLOv8 模型，支持自动标注功能
- 支持类别层级管理（父子类别关系）
- 支持标注可视化编辑和调整
- 支持标注的拖拽排序和重命名

### 项目管理
- 完全采用 SQLite3 数据库存储项目配置和标注数据
- 支持同时打开和管理多个项目窗口
- 自动保存标注到 SQLite 数据库中
- 支持项目数据备份和迁移

## 独特优势

### 智能自动标注
KBoxLabel 集成了先进的 YOLOv8 目标检测模型，能够自动识别图像中的物体并生成标注框，大幅提高标注效率。用户只需加载预训练模型即可享受一键自动标注功能。

### 层级类别管理
支持父子类别结构，允许用户创建复杂的类别体系。例如可以创建"车辆"作为父类别，"汽车"、"卡车"、"摩托车"作为子类别。这种层级结构便于组织和管理复杂的标注类别。

### 高效操作体验
提供丰富的键盘快捷键和鼠标操作支持：
- Ctrl+鼠标滚轮：图像缩放
- 方向键：微调标注框位置
- Shift+方向键：调整标注框边缘
- Ctrl+Shift+方向键：调整标注框大小
- 框选支持多标注框同时操作
- 支持标注列表的拖拽排序
- 支持右键菜单快速操作

## 安装说明

### 系统要求
- Python 3.11
- 支持的操作系统：Windows、macOS、Linux

### 安装步骤

1. 克隆项目仓库：
```bash
git clone https://github.com/kmvdata/KBoxLabel.git
cd KBoxLabel
```

2. 创建虚拟环境（推荐）：
```bash
# 使用 conda 创建虚拟环境
conda create -n kboxlabel python=3.11
conda activate kboxlabel
```

3. 安装依赖：
```bash
# Linux/macOS
bash ./app/pip_install.sh

# Windows
pip install -r app/requirements.txt
```

## 快速入门

### 启动应用
```bash
python src/main.py
```

### 基本操作流程
1. 创建或打开项目
2. 导入图像文件
3. 创建所需的标注类别
4. 进行图像标注
5. 保存标注数据

## 使用指南

### 项目管理
- 点击"新建项目"创建新项目，选择项目保存目录
- 点击"打开项目"打开已有项目
- 从"最近打开的项目"列表中快速访问历史项目

### 图像管理
- 使用"导入图片"功能将图像添加到项目中
- 在左侧图像列表中浏览所有图像
- 右键点击图像可进行重命名、删除等操作
- 支持跳转到指定图像或最后标注的图像

### 标注类别管理
- 在右侧类别列表中管理标注类别
- 支持添加、删除、重命名类别
- 可通过拖拽调整类别顺序
- 支持父子类别关系设置
- 支持修改类别颜色

### 图像标注操作
1. 在类别列表中选择要标注的类别
2. 在图像区域按住鼠标左键拖拽创建标注框
3. 可通过鼠标或键盘调整标注框位置和大小
4. 右键点击标注框可进行删除、置底等操作
5. 支持多选标注框进行批量操作

### 快捷键操作
- `Delete` / `Backspace`：删除选中的标注
- `Ctrl+S`：保存标注
- `Ctrl+鼠标滚轮`：图像缩放
- `Shift+Ctrl+鼠标滚轮`：图像缩放（更精细）
- 方向键：微调选中的标注位置
- `Shift+方向键`：调整选中标注的四边位置
- `Ctrl+Shift+方向键`：调整选中标注的大小

## 自动标注

KBoxLabel 集成了强大的自动标注功能，利用 YOLOv8 模型快速生成高质量的初始标注：

### 配置自动标注
1. 点击工具栏中的"Config"按钮
2. 选择 YOLOv8 模型文件（.pt 格式）
3. 配置置信度阈值、IOU 阈值等参数

### 执行自动标注
1. 右键点击图像列表中的图像
2. 选择"识别"对单张图像进行自动标注
3. 选择"识别多图"对多张图像进行自动标注

### 自动标注参数说明
- **置信度阈值**：过滤低置信度检测结果，值越高结果越可靠但可能遗漏
- **IOU阈值**：非极大值抑制的交并比阈值，用于去除重复检测
- **批次大小**：每次处理的图像数量，影响处理速度和内存占用
- **输入尺寸**：模型输入图像尺寸，影响检测精度和速度

## 数据导出

KBoxLabel 支持将标注数据导出为YOLO格式的训练数据集：

### YOLO数据集导出
1. 点击菜单栏"文件" -> "训练" -> "YOLO数据集"
2. 选择训练数据保存目录
3. 系统将自动按照训练集/验证集比例（默认8:2）组织数据
4. 生成包含images和labels子目录的标准YOLO数据集结构
5. 自动生成dataset.yaml配置文件

### 数据存储结构
所有项目数据（包括标注信息、类别配置等）都存储在项目目录下的 `.kboxlabel` 文件夹中的 SQLite 数据库中，包含：
- 标注信息（`kolo_item` 表）
- 标注类别（`annotation_category` 表）
- 项目配置（`kv_config` 表）

### 支持的图像格式
- JPEG (.jpg, .jpeg)
- PNG (.png)
- BMP (.bmp)
- 其他 PyQt5 支持的图像格式
